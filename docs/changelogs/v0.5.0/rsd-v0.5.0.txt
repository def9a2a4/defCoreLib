# rsd v0.5.0

The first release since 0.3.2 — 0.4.0 was prepared but never published. The indicators live in DefCoreLib, so these changes come from the core.

Needs DefCoreLib 0.5.0 or newer, on Paper 1.21.11 or newer.

- **Pick-block** — middle-clicking a redstone indicator no longer mints a free copy in survival or adventure; it only selects one you already carry (creative still gives it).
- **Catalog** — the indicators show up, with recipes, in the in-game `/defcorelib catalog`.
