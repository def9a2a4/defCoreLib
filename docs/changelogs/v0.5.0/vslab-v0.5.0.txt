# VerticalSlabs v0.5.0

Vertical slabs place against the side of any block, and item-loss fixes.

## Update notes

- **Needs DefCoreLib 0.5.0**, on Paper or Purpur 1.21.11, 26.1.2, 26.2 or 26.3.

## New features

- **Place against any block's side** — a vertical slab no longer needs a solid block behind it.
- **Catalog** — the vertical slabs show up, with recipes, in `/defcorelib catalog`.

## Fixes

- **Placing a vertical slab beside a normal slab no longer destroys it** — next to a normal slab of the same kind it merged into it and wiped it out. That placement is now refused.
- **Pistons pop vertical slabs instead of stripping them** — a pushed slab moved as a plain player head; it now drops as itself.
- **Pick-block** selects a vertical slab you carry instead of minting one in survival or adventure (creative still gives it).
