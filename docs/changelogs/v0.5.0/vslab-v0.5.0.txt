# vslab v0.5.0

The first release since 0.3.2 (0.4.0 was never published). Vertical slabs place against any block, and two item-loss fixes.

## Update notes

- **Needs DefCoreLib 0.5.0 or newer**, on Paper or Purpur 1.21.11 or newer.

## New features

- **Place against anything** — a vertical slab no longer needs a solid block behind it.

## Fixes

- **Placing a vertical slab beside a normal slab no longer destroys it** — next to a bottom slab of the same wood it merged into it and wiped it out. That placement is now refused.
- **Pistons no longer strip vertical slabs** — a pushed slab dropped as a plain player head; it now drops as itself.
