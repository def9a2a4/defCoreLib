# vslab v0.5.0

The first release since 0.3.2 — 0.4.0 was prepared but never published, so the changes below are new to you.

Needs DefCoreLib 0.5.0 or newer, on Paper 1.21.11 or newer.

- **Vertical slabs no longer require a solid supporting block to place.** You can now place a vertical slab against non-solid blocks too, instead of the placement being refused without a solid backing block.
- **Placing a vertical slab beside a normal slab no longer destroys it.** Clicked next to a bottom slab of the same wood, the vertical slab merged into it and wiped it out. That placement is now refused.
