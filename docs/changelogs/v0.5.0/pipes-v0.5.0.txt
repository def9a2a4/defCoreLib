# Pipes v0.5.0

The first release since 0.3.2 (0.4.0 was never published). Three **filter pipes** that only pass the items you choose, land-claim checks, and pipe fixes.

## Update notes

- **Needs DefCoreLib 0.5.0**, on Paper or Purpur 1.21.11, 26.1.2, 26.2 or 26.3.
- **`config.yml` is migrated on first start.** Pipe types now come from the plugin itself, so the `variants:`, `cauldron-conversions:` and `conversion-recipes:` sections are removed (your old file is kept as `config-pre-0.5.0.yml`), and per-type transfer rates are no longer read. To turn a pipe type off, list it under the new `disabled-pipes:` — after a restart it is uncraftable and leaves `/pipes give`, while placed ones keep working.
- **`/pipes recipes` and the `pipes.recipes` permission are gone** — pipe recipes are discovered automatically, and the oxidized-pipe water-bucket recipes are built in.
- **Permissions:** `/pipes` itself no longer requires `pipes.admin`; each subcommand checks its own (`pipes.give`, `pipes.info`, `pipes.reload`, `pipes.migrate`, `pipes.delete_all`; `pipes.admin` still grants them all). Someone granted only `pipes.give` can now use `/pipes give`, including to other players.

## New features

- **Filter pipes** — **Copper**, **Iron** and **Gold Filter Pipe** pass only the items you choose. Put one at a container to pull only matching items, or mid-line to block the rest; two in series must both allow an item. Several on one chest, each feeding a different destination, sort items with no extra machinery.
  - **Copper:** 5 slots, whitelist, match by type. **Iron:** 9 slots, whitelist/blacklist toggle. **Gold:** 18 slots, plus exact matching (names, enchants, components).
  - Right-click to open the filter. Click an item into a slot to add a copy of it to the filter — your item isn't used up — and click a slot with an empty hand to clear it. Nothing is stored in the pipe, so breaking or moving it never drops or loses anything, and several players can edit one filter.
  - Redstone next to the pipe switches it **off**, stopping its whole line; the ring around the pipe goes dark to show it.
  - Throughput matches the plain pipe of the same metal (4 / 8 / 16 items per transfer). Filter pipes carry items only, not fluids.
  - **Craft:** the metal's plain-pipe pattern with a hopper in place of the redstone → 2 filter pipes.
  - An unconfigured filter (empty whitelist) blocks **everything**, so a fresh filter dropped into a working line stops it until set up. A machine pushing straight down into a filter backs up instead of leaking past it — to gate a machine's output, send it into a chest and filter from there. Filtering isn't applied yet while a filter pipe rides a moving mechanism.
- **Machines can feed machines through a pipe** — output dropped into a pipe reaches a mech machine at the end of the line, not just a chest.
- **`/pipes` and `/pipes help`** show what Pipes does, the commands you may use, and the GitHub and Discord links.
- **`/pipes give <item|ALL> [amount] [player]`** gives to another player and works from the console; with `ALL` the amount applies to each pipe type.
- **Pipes respect land claims** — a pipe can't be placed against a container you aren't allowed to open, so a claimed chest can't be drained or stuffed from outside.

## Fixes

- **Pipes in a cauldron with a hopper underneath** — converting copper pipes to oxidized converted items the hopper had already pulled out a second time.
- **A dead-end pipe stops spilling as soon as you put a container at its end** — it kept dropping items until a stale timer ran out.
- **No water in the Nether** — a fluid pipe no longer pours water where water evaporates.
- **No shulker boxes inside shulker boxes.**
- **Redstone beside a pipe no longer costs the whole world** — any redstone change next to any pipe made every pipe recompute its route, and a filter pipe switching back on woke every idle pipe. Now only the pipes it affects react, so a redstone clock next to a filter pipe stays cheap.
- A server error when the pipe set changed while the network was ticking.
- Pipes keep working in a world whose unload another plugin cancelled.
