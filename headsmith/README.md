# HeadSmith

~3,300 decorative player-head blocks as DefCoreLib data — barrels, candles, chimneys, the full
alphabet, mini-blocks, and more. A companion module of
[DefCoreLib](https://github.com/def9a2a4/defCoreLib). The heads are defined in DefCoreLib's
`headsmith` namespace; this thin jar loads them, enables their recipes, and adopts heads placed by
the old standalone HeadSmith plugin.

**Requires [DefCoreLib](https://github.com/def9a2a4/defCoreLib).**
